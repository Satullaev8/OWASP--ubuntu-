# Vulnerable Ubuntu Server - Pentesting Lab

This project is a custom-built virtual laboratory environment featuring an Ubuntu server intentionally configured with various security vulnerabilities. It is designed to help cybersecurity enthusiasts and aspiring penetration testers sharpen their skills. The server hosts 13 individual websites, each containing different security flaws.

## 🚀 About the Lab
This lab was created for educational purposes, focusing on the following areas:
* **Web Application Security:** Practical exercises based on the OWASP Top 10.
* **Privilege Escalation:** Techniques for gaining elevated access within a Linux environment.
* **Network Auditing:** Identifying open services and potential entry points.

## 🛠 Vulnerabilities Included
The 13 websites hosted on this server include classic vulnerabilities such as:
* **SQL Injection (SQLi):** Exploiting database queries.
* **Cross-Site Scripting (XSS):** Executing malicious scripts in a user's browser.
* **Local File Inclusion (LFI):** Reading sensitive system files.
* **Command Injection:** Executing OS commands directly on the server.
* **Broken Authentication:** Bypassing login mechanisms and session management.
* ...and many more.

## ⚙️ Setup and Installation
1. Download a virtualization platform like **VMware** or **VirtualBox**.
2. Import the provided `.ova` file.
3. Configure the Network Settings to **Bridged Adapter** or **NAT** mode.
4. Start the virtual machine.
